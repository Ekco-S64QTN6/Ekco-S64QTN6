## 🧭 About this corner of GitHub

I build open-source tools where **AI, automation, reverse engineering, simulation, and security** intersect.

Some projects run local AI agents. One turns *Master of Orion*'s 1993 game assets into an unscripted live newscast. Another keeps a Dwarf Fortress stream running unattended. Others help with wireless research, hardened AI administration, or headless binary triage.

The common thread: **make complicated systems observable, useful, and capable of running on their own.**

## 🧰 What I work on

- **Local-first AI:** agents and assistants designed to run on infrastructure I control.
- **Autonomous systems:** software that can observe state, make decisions, recover, and keep operating without constant supervision.
- **Reverse engineering:** understanding legacy game assets, binary formats, and the systems built around them.
- **Security and analysis:** practical tooling that turns low-level evidence into reports people can act on.
- **Simulation and creative automation:** combining real inputs, game systems, media, and a little controlled chaos.
